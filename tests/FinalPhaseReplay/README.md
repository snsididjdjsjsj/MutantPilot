# 末阶段开发筛查

FinalPhaseReplay 和旁边的 VoidPhaseReplay 只用于孤立阶段的反事实路线实验。它们复用真实控制器的纯移动/规划核心、读取已关闭的实机日志初态，并按确定性规律计算弹幕。程序不连接游戏、不修改存档。

输出强制标为 `developmentOnly=true`、`victoryCertification=false`。目前没有真实引擎碰撞、起点随机抖动、后续装备/状态变化或完整跨阶段实体；在一些实机失败初态上，连旧策略也能在这里通过。因此没有通过“重放原动作复现旧失败”的完整校准，不能用这些结果比较实机无伤率、证明某个改动有效，或替代完整实机验收。

出生计时与速度的独立实机对照由 SphereSpawnChecks、MarkSpawnChecks 完成。这些局部对照也不意味着完整路线仿真准确。
